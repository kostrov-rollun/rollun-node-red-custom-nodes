# Custom rollun node-red nodes

### Local develompent

To develop locally, run 
```sh
npm run start:dev
```
in project root, this will open up node-red on http://localhost:1880
with all custom nodes installed

### How to update SP-API models

```sh
chmod +x scripts/update-sp-api-models.sh
./scripts/update-sp-api-models.sh
```
